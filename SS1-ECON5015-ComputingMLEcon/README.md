# ECON 5015: Computing and Machine Learning for Economics

## Directory Structure
- **`Modules/`**: Official course materials synced from Canvas, organized into directed modules:
  - `01-Introduction-to-Python/`: Python basics, conditional execution, iterables, looping, practice quizzes and solutions
  - `02-Working-with-Data/`: NumPy arrays, Pandas dataframes, statsmodels, datasets (Yahoo finance, London crime)
  - `03-More-Python-Programming/`: Mutability, functions, debugging techniques, classes, and dictionaries
  - `04-Algorithmic-Efficiency/`: Algorithmic efficiency, homework, practice midterms and solutions, shortest path assignment
- **`In_Class_Notebooks/`**: In-class working Jupyter notebooks, exercises, and student notes.
- **`Homeworks/`**: Submitted and in-progress weekly assignments.
- **`Scripts/`**: Python standalone scripts, quizzes, and helper modules.
- **`Random/`**: Scratch experiments and scratch testing code.
