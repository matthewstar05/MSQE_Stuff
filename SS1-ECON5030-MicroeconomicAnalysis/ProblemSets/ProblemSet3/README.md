# Problem Set 3 Workspace

## Overview
Problem Set 3 covers Cournot duopoly and oligopoly with quadratic costs (equilibrium, surplus and deadweight loss), Cournot with differentiated products, and Bertrand price competition with increasing marginal cost (no pure-strategy equilibrium; mixed-strategy equilibrium).
