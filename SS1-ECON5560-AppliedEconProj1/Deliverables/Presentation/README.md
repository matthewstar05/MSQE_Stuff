# Presentation Deliverables

This directory contains slide decks and presentation materials as specified in [Replication_Guidance.md](../Replication_Guidance.md).

## Structure & Milestones
- **Draft (Week 8)**: Initial 2-slide appraisal presentation draft.
- **Final (Week 10)**: Final slide deck for team presentation and client briefing.

## Recommended Presentation Formats
- Slides source (`.qmd`, `.pptx`, or `.pdf`)
- Visual figures should link to or import from [`Replication-Project/Data-Parsing/output/`](../../Replication-Project/Data-Parsing/output/) generated by `06_slide_figures.py`.
- Presentation guidance and Duarte/Zettlemeyer resources: [`Resources/`](Resources/) (including [`Resources_for_Presentations.html`](Resources/Resources_for_Presentations.html)).
