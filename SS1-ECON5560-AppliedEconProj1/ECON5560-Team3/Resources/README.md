# Resources

Supporting files for the replication. The code in `../Data-Parsing` reads the data file from this folder.

| File | What it is |
|---|---|
| `Eppink_2016_PLoSONE_paper.pdf` | The paper we replicate: Eppink, Winden, Wright & Greenhalgh (2016), *PLoS ONE* 11(10): e0165365. Open access, CC BY 4.0 |
| `S1Table.DTA` | The authors' supplementary data ("S1 Table", Stata format): 2,160 rows = 180 respondents × 4 cards × 3 options. Published with the paper under CC BY 4.0. **Do not edit.** Every cleaning step happens in code |
| `Team3_Charter.pdf` | Our team charter: roles, communication, decision rules, AI-use policy |
| `COURSE_REQUIREMENTS.md` | Our own summary of the course's replication timeline, memo requirements, and presentation norms |

**Deliberately not included:** saved Canvas pages and the course syllabus. Saved Canvas pages embed personal account identifiers, and the syllabus contains private meeting links. The authoritative versions are on Canvas.
